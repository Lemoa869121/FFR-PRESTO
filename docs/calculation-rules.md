# Règles de calcul

> Document prêt à recevoir les règles métier Forster. **Aucune règle n’est renseignée tant qu’elle n’a pas été fournie ou démontrée par un document source.**

## Conventions

- Chaque règle a un identifiant stable (`P-<domaine>-<n°>`), un statut et au moins une source.
- Statuts : `explicite` (lue dans la source), `derivee` (déduite de cas réels et vérifiée sur tous), `a_valider`, `manquante`.
- Unités : millimètres pour les longueurs de coupe, mètres pour les joints, pièces pour le reste.
